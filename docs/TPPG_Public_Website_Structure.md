# TPPG Public Website Structure

## 1. Website Purpose

The TPPG public website will serve as the buyer-facing platform of The Premier Property Group (TPPG).

Its primary goals are:

- Generate property buyer leads
- Increase property sales
- Make TPPG discoverable through Google Search
- Showcase available properties and developments
- Help buyers find properties based on location, budget, property type, and needs
- Connect interested buyers with TPPG property specialists
- Build trust and credibility for TPPG

### Main Buyer Funnel

Google / Social Media
→ TPPG Website
→ Property Search / Property Page
→ Buyer Inquiry
→ Lead
→ Property Specialist
→ Viewing / Consultation
→ Reservation
→ Sale

The existing TPPG Portal remains the internal system for agents, managers, sales, buyers, commissions, and property management. The public website should not expose the internal portal to buyers.
